Description
A 2D side-scrolling platformer focusing on mechanics-driven gameplay and pixel-art aesthetics. Developed using Python and Pygame for game loops and rendering logic.

Features
Character Control: Physics-based player movement and health management (Ruch gracza oparty na fizyce i zarządzanie zdrowiem).

Enemy Logic: Automated patrolling entities with overhead health indicators (Zautomatyzowani przeciwnicy ze wskaźnikami zdrowia).

Level Architecture: Multi-level environment with interactive elements and layered backgrounds (Wielopoziomowe środowisko z interaktywnymi elementami).

User Interface: HUD for real-time tracking of player and enemy status (Interfejs HUD do śledzenia stanu w czasie rzeczywistym).

Tech Stack
Language: Python

Library: Pygame

Academic Context 
Final project for 1st-semester computer science, demonstrating object-oriented programming and event-driven logic (Projekt końcowy na pierwszy semestr informatyki, demonstrujący programowanie obiektowe i logikę sterowaną zdarzeniami).

Installation
Ensure Python is installed.

Install Pygame: pip install pygame.

Run the game: python main.py.
